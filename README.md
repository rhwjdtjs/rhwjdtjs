# 고정선 · 게임 클라이언트 개발자

Unreal Engine 5와 C++을 중심으로 게임플레이를 개발합니다. 개인 개발팀 TEAM NIRIZ에서 게임을 만들고 출시 후 수정과 업데이트를 이어가고 있습니다.

 [개발 블로그](https://jeongseondevlog.tistory.com/)

## 주요 프로젝트

### TOOSIN · 투신

검투사 액션 로그라이크를 1인 개발해 Steam과 STOVE에 정식 출시했습니다. 근접 전투와 패링, 플레이어 행동 표본을 반영하는 적 AI, Steam 리더보드와 그래픽 옵션을 구현했습니다.

현재 공개 업데이트 기록은 v1.3.1까지이며 Codex와 Claude를 활용해 v1.4 업데이트를 준비하고 있습니다. 개발본에 반영한 기능과 검수 결과는 공개 문서에 구분해 정리합니다.

[개발 문서](https://github.com/rhwjdtjs/Toosin_Public) · [Steam](https://store.steampowered.com/app/4635530/TOOSIN/) · [STOVE](https://store.onstove.com/ko/games/104376)

### SINGULARITY

3인 팀으로 개발 중인 1인칭 바디캠 생존 공포 게임입니다. 리드 개발자·PM으로 플레이어 조작, 바디캠, 무기와 공용 체력 기반을 구현하고 작업 분담과 팀 통합을 맡고 있습니다.

MVP1의 기본 플레이 흐름을 통합한 뒤 기능을 확장하고 있습니다. 개인 구현과 팀원의 기여, 개발본 반영과 플레이 검수 범위를 각각 기록합니다.

[개발 문서와 팀 기여](https://github.com/rhwjdtjs/SINGULARITY-Portfolio) · [구현 상세](https://teamniriz.com/portfoliosecret#singularity)

### NONGJANG · 농장

동물과의 교감, 사냥·채집·정착을 다루는 섬 생존 게임을 1인 개발하고 있습니다. 동물의 상태와 우선순위 판단, 근거리·원거리 생태 처리, 관계와 월드 상태의 저장·복원을 만들고 있습니다.

기획과 요구사항을 정하고 Codex·Claude를 코드 작성과 검토에 활용합니다. 현재는 기능 구현과 통합 단계입니다. 월드·외형·그래픽을 다듬고 있으며 실제 두 PC 멀티플레이와 패키지 검수는 후속 작업입니다.

[공개 개발 문서](https://github.com/rhwjdtjs/NONGJANG_Public) · [구현 상세](https://teamniriz.com/portfoliosecret#nongjang)

### VELOCORE

Unreal Engine 5·C++로 만든 1인 개발 멀티플레이 TPS입니다. Steam OSS와 리슨 서버를 사용해 전투·와이어 이동을 동기화하고 10인 온라인 테스트를 진행했습니다.

[코드](https://github.com/rhwjdtjs/Velocore) · [플레이 영상](https://youtu.be/35-OI47LQC0)
